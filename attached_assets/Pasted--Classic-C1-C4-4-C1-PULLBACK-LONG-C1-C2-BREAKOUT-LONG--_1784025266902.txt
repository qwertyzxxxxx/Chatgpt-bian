任务：新增 Classic C1～C4 经典量价策略

【核心目标】

新增4套独立的经典量价策略：

C1_PULLBACK_LONG
中文名：C1 回踩多

C2_BREAKOUT_LONG
中文名：C2 突破多

C3_RALLY_SHORT
中文名：C3 反弹空

C4_EXTREME_REVERSAL
中文名：C4 极端反转

核心原则：

1. 涨跌幅排名只负责选币，不能直接决定交易方向。
2. 价格结构决定方向，成交量负责确认。
3. 没有有效量能，不产生正式信号。
4. 做多不能追在严重高位。
5. 做空不能空在严重低位。
6. 只使用已经收盘的K线。
7. 不增加周线、月线。
8. 不修改V3、V66、V662、V663、V664、Wave等现有策略。
9. Classic系列第一阶段只运行PAPER，不连接实盘下单。
10. 所有阈值写入配置文件，禁止散落硬编码。

==================================================
一、动态币池
==================================================

每15分钟扫描一次 Binance U本位永续全市场。

第一步：基础过滤

只保留：

1. USDT本位永续合约。
2. 当前状态为TRADING。
3. 24小时成交额 quoteVolume ≥ 30,000,000 USDT。
4. 排除稳定币交易对。
5. 排除杠杆代币和交割合约。
6. K线历史完整。
7. 排除价格、成交量和点差明显异常的币。

成交额必须使用：

24h quoteVolume

禁止使用baseVolume。

第二步：涨跌幅排名

在完成成交额过滤之后，按照24小时涨跌幅排名。

上涨池：

24小时涨幅从高到低排序，取前20名。

标记：

pool_type = TOP_GAINERS
pool_rank = 1～20

下跌池：

24小时涨幅从低到高排序，取跌幅前20名。

标记：

pool_type = TOP_LOSERS
pool_rank = 1～20

两个池合并后最多40个币。

如果符合成交额要求的币不足20个，使用实际数量。

禁止加入低成交额币补足名额。

禁止固定加入BTC、ETH或任何核心币种。

==================================================
二、策略与币池对应
==================================================

C1 回踩多：

扫描涨幅前20名。

寻找上涨趋势形成后的第一次缩量回踩。

C2 突破多：

扫描涨幅前20名。

寻找平台放量突破后的缩量回踩。

C3 反弹空：

扫描跌幅前20名。

寻找下降趋势中的缩量反弹失败。

C4 极端反转：

C4_TOP_SHORT扫描涨幅前20名。

C4_BOTTOM_LONG扫描跌幅前20名。

涨幅榜不能直接做空。

跌幅榜不能直接抄底。

必须经过时间、空间、量能和价格结构确认。

==================================================
三、统一分析周期
==================================================

日线D：

1. 3日涨跌幅。
2. 7日涨跌幅。
3. 30日最高价。
4. 30日最低价。
5. 30日区间位置。
6. 连续上涨或下跌天数。

30日区间位置：

range_position_30d =
(current_price - low_30d)
/
(high_30d - low_30d)

4H：

1. EMA20。
2. EMA60。
3. ATR14。
4. EMA20方向。
5. 价格距离EMA20多少ATR。
6. 主要趋势方向。

1H：

1. EMA20。
2. 最近20根局部高低点。
3. 平台结构。
4. Higher Low或Lower High。
5. 成交量比。
6. K线实体和影线结构。

15m：

1. EMA20。
2. ATR14。
3. 局部高低点。
4. 回踩确认。
5. 重新启动量能。
6. Entry和结构止损。

所有周期只允许使用已经收盘的K线。

禁止读取正在形成的K线参与信号判断。

==================================================
四、统一量价模块
==================================================

成交量统一使用quote_volume成交额。

量比：

vol_ratio =
当前已收盘K线quote_volume
/
前20根已收盘K线quote_volume中位数

使用中位数，避免前面极端巨量影响均量。

同时计算：

close_location =
(close - low) / (high - low)

body_ratio =
abs(close - open) / (high - low)

upper_wick_ratio =
(high - max(open, close)) / (high - low)

lower_wick_ratio =
(min(open, close) - low) / (high - low)

如果high等于low，以上结果记为0，禁止除零报错。

多头强势收盘：

close_location ≥ 0.70

空头强势收盘：

close_location ≤ 0.30

==================================================
五、量价等级
==================================================

NORMAL：

vol_ratio 1.2～1.5。

只能作为辅助确认，不能单独产生信号。

A级：

vol_ratio 1.5～2.0。

价格正常突破、跌破或重新启动。

目标约1.5R～2R。

S级：

vol_ratio 2.0～4.0。

价格有效突破或跌破，并在强势位置收盘。

目标约2R～3R。

S_PLUS级：

vol_ratio 4.0～8.0。

属于极强启动、清算或情绪爆发。

禁止直接追单，必须等待后续15m或1H确认结构守住。

确认成功后，目标约3R～5R或使用结构移动止盈。

EXHAUSTION衰竭级：

vol_ratio ≥ 3.0，

但价格没有继续有效推进，并出现以下任一情况：

1. 巨量长上影。
2. 巨量长下影。
3. 突破后重新收回平台。
4. 跌破后重新站回平台。
5. 巨量但涨幅或跌幅很小。
6. 创新高或创新低后快速失败。

衰竭级禁止顺势追单。

根据位置转入：

C4_TOP_SHORT观察池

或

C4_BOTTOM_LONG观察池。

注意：

量能越大，不允许自动扩大止损。

==================================================
六、C1 回踩多
==================================================

策略ID：

C1_PULLBACK_LONG

适用图形：

上涨趋势
→ 前一轮放量上涨
→ 第一次缩量回踩
→ 形成Higher Low
→ 再次放量转强

4H趋势条件：

1. close > EMA20 > EMA60。
2. EMA20方向向上。
3. 当前价格距离EMA20 ≤ 1.5 ATR。

禁止追多条件：

以下3项满足2项，禁止产生C1信号：

1. 7日涨幅 > 40%。
2. 30日位置 > 0.90。
3. 价格距离4H EMA20 > 2 ATR。

1H图形条件：

1. 前一轮上涨量比 ≥ 1.5。
2. 上涨K线收盘位置偏强。
3. 随后第一次回踩EMA20或原突破平台。
4. 回踩平均量比 ≤ 0.8。
5. 回踩没有跌破重要结构低点。
6. 形成Higher Low。

15m入场条件：

1. 回踩后重新站上EMA20。
2. 突破确认K线高点。
3. 重新启动量比 ≥ 1.2。
4. 当前价格没有明显远离入场结构。

没有前一轮放量上涨，不产生C1信号。

==================================================
七、C2 突破多
==================================================

策略ID：

C2_BREAKOUT_LONG

适用图形：

平台整理
→ 波动收缩
→ 放量突破
→ 缩量回踩平台
→ 再次上涨

平台要求：

1. 最近至少20根1H K线形成相对清楚的平台。
2. 平台高低点至少被测试两次。
3. 平台宽度不能异常大。
4. 突破前7日涨幅 ≤ 30%。
5. 突破前30日位置 ≤ 0.90。
6. 突破前价格距离4H EMA20 ≤ 1 ATR。

1H突破条件：

1. 已收盘1H K线突破平台最高点。
2. 突破量比 ≥ 2.0。
3. close_location ≥ 0.70。
4. 上影线不能过长。
5. 突破后距离4H EMA20不能超过2 ATR。

禁止在突破K线直接追多。

15m回踩入场：

1. 回踩原平台或EMA20。
2. 回踩量比 ≤ 0.8。
3. 收盘不能有效跌回原平台内部。
4. 形成Higher Low。
5. 重新突破确认K线高点。
6. 重新启动量比 ≥ 1.2。

突破量比不足2倍，不产生C2信号。

如果突破达到4～8倍量，但出现长上影或跌回平台：

标记EXHAUSTION，不做多，转入C4观察。

==================================================
八、C3 反弹空
==================================================

策略ID：

C3_RALLY_SHORT

适用图形：

下降趋势
→ 前一轮放量下跌
→ 缩量反弹
→ 形成Lower High
→ 再次放量转跌

4H趋势条件：

1. close < EMA20 < EMA60。
2. EMA20方向向下。
3. 当前价格已经从低位反弹，接近EMA20或原破位平台。

禁止追空条件：

以下3项满足2项，禁止产生C3信号：

1. 7日跌幅超过35%。
2. 30日位置 < 0.15。
3. 价格低于4H EMA20超过2 ATR。

1H图形条件：

1. 前一轮下跌量比 ≥ 1.5。
2. 下跌K线收盘位置偏弱。
3. 随后出现缩量反弹。
4. 反弹平均量比 ≤ 0.8。
5. 反弹无法突破EMA20或原支撑平台。
6. 形成Lower High。

15m入场条件：

1. 反弹无法站稳EMA20。
2. 收盘重新跌回EMA20下方。
3. 跌破确认K线低点。
4. 重新转跌量比 ≥ 1.2。

没有前一轮放量下跌，不产生C3信号。

价格仍在30日极低位置时，不允许继续追空。

==================================================
九、C4 极端反转
==================================================

策略ID：

C4_EXTREME_REVERSAL

包含两个方向：

C4_TOP_SHORT
中文：顶部反转空

C4_BOTTOM_LONG
中文：底部反转多

--------------------------------------------------
C4_TOP_SHORT
--------------------------------------------------

只扫描涨幅前20名。

排名只用于进入观察池，不能直接做空。

时间和空间条件：

1. 连续上涨至少3天。
2. 7日涨幅 ≥ 30%。
3. 30日位置 ≥ 0.85。
4. 价格距离4H EMA20 ≥ 1.5 ATR。

量价衰竭条件：

1. 冲顶量比 ≥ 3.0。
2. 出现以下任一现象：
   - 长上影；
   - 创新高后快速收回；
   - 巨量但价格上涨很少；
   - 突破后收盘重新跌回平台；
   - 收盘位于K线中部或下部。
3. 1H跌破EMA20或最近局部低点。
4. 后续反弹量明显缩小。
5. 反弹无法突破前高或原破位位置。

15m入场：

1. 形成Lower High。
2. 反弹无法站稳EMA20。
3. 收盘重新跌回EMA20下方。
4. 跌破确认K线低点。

必须排除：

1. 过去30天仍在明显低位、今天只是底部反弹。
2. 只有第一天上涨。
3. 刚刚突破长期平台。
4. 4H趋势刚刚转强。
5. 1H仍在连续创新高。
6. 巨量突破后价格稳定守在平台上方。

--------------------------------------------------
C4_BOTTOM_LONG
--------------------------------------------------

只扫描跌幅前20名。

排名只用于进入观察池，不能直接抄底。

时间和空间条件：

1. 连续下跌至少3天。
2. 7日跌幅 ≥ 25%。
3. 30日位置 ≤ 0.15。
4. 价格距离4H EMA20 ≥ 1.5 ATR。

量价衰竭条件：

1. 恐慌量比 ≥ 3.0。
2. 出现以下任一现象：
   - 长下影；
   - 跌破低点后快速收回；
   - 巨量但价格不再继续下跌；
   - 收盘重新站回原支撑；
   - 收盘位于K线中部或上部。
3. 1H停止连续创新低。
4. 形成Higher Low。
5. 重新站上1H EMA20或突破局部高点。

15m入场：

1. 回踩没有跌破前低。
2. 形成Higher Low。
3. 重新站上EMA20。
4. 突破确认K线高点。
5. 重新启动量比 ≥ 1.2。

必须排除：

1. 上涨趋势中的第一天下跌。
2. 刚刚放量跌破长期平台。
3. 1H仍然连续创新低。
4. 只有超跌，没有价格结构转强。
5. 巨量下跌后仍然收盘接近最低点。

==================================================
十、统一止损
==================================================

所有策略使用结构止损。

做多：

最近15m结构低点
-
0.2 × 15m ATR14

做空：

最近15m结构高点
+
0.2 × 15m ATR14

规则：

1. 止损距离超过6%，放弃信号。
2. 不允许因为量比达到3倍、5倍或8倍而扩大止损。
3. 止损距离变宽，只能降低仓位。
4. 禁止固定百分比止损覆盖结构止损。
5. 保存原始结构位置和最终止损计算过程。

==================================================
十一、动态止盈
==================================================

交易前必须存在至少1.5R的可用结构空间。

A级：

TP1 = 1.5R。

S级：

TP1 = 2R。

S_PLUS级：

确认结构有效后，TP1 = 3R。

到达TP1后：

平仓50%。

剩余50%使用15m价格结构移动止损。

多头：

跌破最近Higher Low退出。

空头：

突破最近Lower High退出。

C2突破多：

剩余仓位可持有到下一处4H压力位。

C3反弹空：

剩余仓位可持有到下一处4H支撑位。

C4极端反转：

剩余仓位可持有到4H结构目标，允许达到3R～5R。

禁止仅因量比高就直接设置5R。

必须同时满足：

1. 价格结构有效。
2. 后续确认守住突破或跌破位置。
3. 目标前没有更近的重要支撑或压力。

==================================================

总分100：

时间与空间位置：30分。

4H和1H趋势：25分。

价格图形完整度：25分。

量价配合：20分。

处理：

总分 ≥ 75：

允许产生正式PAPER信号。

总分65～74：

进入观察池，不推送正式信号。

总分 < 65：

忽略。

评分不能绕过：

禁止追多条件。

禁止追空条件。

流动性条件。

价格结构条件。

最低量能条件。

相同symbol、相同方向、24小时内：

只保留评分最高的正式信号。

保留评分最高策略。

其他策略记录为重叠候选，不重复推送。

不得为了增加信号数量降低量能、结构或流动性要求。
