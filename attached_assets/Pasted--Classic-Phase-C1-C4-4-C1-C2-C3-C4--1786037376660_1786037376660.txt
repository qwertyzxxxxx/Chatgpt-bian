任务：开发 Classic Phase C1～C4 四套新策略

目标：
新增4套独立策略，按照币种当前所处阶段产生信号：

C1 底部启动多
C2 主升回踩多
C3 高位衰竭空
C4 恐慌反转多

核心原则：

1. 排名只负责选币，不能直接决定方向。
2. 时间 + 空间 + 量价结构决定属于哪种行情。
3. EMA只作辅助，不作为唯一入场依据。
4. 没有有效成交量，不产生信号。
5. 不允许涨太高后继续追多。
6. 不允许跌到底部后继续追空。
7. 只使用已收盘K线。
8. 新策略只运行PAPER，不接LIVE。
9. 不修改V3、V66、V662、V663、V664、Wave等现有策略。
10. 四套策略分别统计，不混合成绩。

==================================================
一、动态扫描币池
==================================================

每15分钟扫描 Binance USD-M Futures 全市场。

基础过滤：

1. USDT本位永续合约。
2. 合约状态为TRADING。
3. 24h quoteVolume >= 30,000,000 USDT。
4. 排除稳定币、杠杆代币、交割合约。
5. K线数据完整。
6. 排除异常价格、异常K线。

必须先完成成交额过滤，再排名。

上涨池：

按24h涨跌幅从高到低取前20名。

pool_type = TOP_GAINERS

下跌池：

按24h涨跌幅从低到高取前20名。

pool_type = TOP_LOSERS

不足20个时使用实际数量，不得加入低成交额币补足。

BTC、ETH不固定加入，只有进入排名才扫描。

==================================================
二、统一周期和数据
==================================================

D（日线）负责时间和空间：

- ret_1d
- ret_3d
- ret_7d
- high_30d
- low_30d
- range_position_30d
- distance_from_30d_high
- distance_from_30d_low
- consecutive_up_days
- consecutive_down_days

range_position_30d：

(current_price - low_30d)
/
(high_30d - low_30d)

4H负责主要趋势和是否过度延伸：

- EMA20
- EMA60
- ATR14
- EMA20 slope
- price_distance_to_ema20_atr

1H负责识别主要图形：

- EMA20
- 最近20根高低点
- 平台突破/跌破
- Higher Low
- Lower High
- 成交量和K线结果

15m负责入场和结构止损：

- EMA20
- ATR14
- 局部高低点
- 回踩/反弹确认
- 再启动量能

禁止使用未收盘K线。

==================================================
三、统一量价模块
==================================================

量比使用quote volume：

vol_ratio =
当前已收盘K线quote_volume
/
前20根已收盘K线quote_volume中位数

同时计算：

close_location =
(close - low) / (high - low)

body_ratio =
abs(close - open) / (high - low)

upper_wick_ratio
lower_wick_ratio

量价等级：

A：
vol_ratio 1.5～2.0

S：
vol_ratio 2.0～4.0

S_PLUS：
vol_ratio 4.0～8.0

EXHAUSTION：
vol_ratio >= 3.0，
但价格没有相应推进，出现长影线、假突破、假跌破或巨量滞涨/止跌。

注意：

量能大不等于一定顺势。
必须判断“有这么大的量，价格最终走出了什么结果”。

==================================================
四、C1 底部启动多
==================================================

策略ID：

C1_BOTTOM_START_LONG

中文：

C1 底部启动多

扫描：

涨幅前20。

目标图形：

长期下跌或低位整理
→ 底部放量
→ 突破平台
→ 第一次缩量回踩
→ 再次转强做多

必须满足：

1. 过去30天曾明显下跌或长期低位整理。
2. 当前30日位置在0.15～0.65之间。
3. 不能已经处于30日最高区域。
4. 最近1～10天内出现阶段低点。
5. 1H收盘突破最近20根平台高点。
6. 突破量比 >= 2.0。
7. 突破K close_location >= 0.70。
8. 突破前7日涨幅不能已经超过35%。

禁止直接追突破K。

15m入场：

1. 突破后第一次回踩平台或EMA20。
2. 回踩量比 <= 0.8。
3. 没有跌回平台深处。
4. 形成Higher Low。
5. 重新站上EMA20。
6. 突破确认K高点。
7. 再启动量比 >= 1.2。

禁止信号：

- 今天只是暴涨后离4H EMA20超过2 ATR。
- 30日位置 > 0.90。
- 突破后没有回踩。
- 巨量突破后出现长上影并跌回平台。

==================================================
五、C2 主升回踩多
==================================================

策略ID：

C2_TREND_PULLBACK_LONG

中文：

C2 主升回踩多

扫描：

涨幅前20。

目标图形：

上涨趋势已经建立
→ 前一轮放量上涨
→ 第一次缩量回踩
→ Higher Low
→ 再次放量转强

4H趋势：

1. close > EMA20 > EMA60。
2. EMA20方向向上。
3. 当前价格距离EMA20 <= 1.5 ATR。

禁止追高：

以下3项满足任意2项，禁止做多：

1. ret_7d > 40%。
2. range_position_30d > 0.90。
3. 距离4H EMA20 > 2 ATR。

1H图形：

1. 前一轮上涨量比 >= 1.5。
2. 上涨K线收盘位置偏强。
3. 随后第一次回踩EMA20或原突破平台。
4. 回踩量比 <= 0.8。
5. 没有跌破上一结构低点。
6. 形成Higher Low。

15m入场：

1. 重新站上EMA20。
2. 突破确认K高点。
3. 再启动量比 >= 1.2。

没有“上涨放量、回踩缩量、再涨重新放量”的完整顺序，不产生信号。

==================================================
六、C3 高位衰竭空
==================================================

策略ID：

C3_TOP_EXHAUSTION_SHORT

中文：

C3 高位衰竭空

扫描：

涨幅前20。

目标图形：

连续上涨多日
→ 高位巨量
→ 价格涨不动
→ 1H结构转弱
→ 15m反弹失败做空

时间和空间：

1. 连续上涨至少3天。
2. ret_7d >= 30%。
3. range_position_30d >= 0.85。
4. 距离4H EMA20 >= 1.5 ATR。

量价衰竭：

1. 冲顶量比 >= 3.0。
2. 出现以下任一情况：
   - 长上影；
   - 创新高后快速收回；
   - 巨量但价格上涨很小；
   - 收盘跌回突破平台；
   - close_location < 0.50。
3. 1H跌破EMA20或最近局部低点。
4. 随后反弹成交量缩小。
5. 形成Lower High。

15m入场：

1. 反弹到EMA20或原破位位置。
2. 无法重新站稳。
3. 收盘重新跌回EMA20下方。
4. 跌破确认K低点。
5. 转跌量比 >= 1.2。

必须排除：

- 底部刚反弹进入涨幅榜。
- 只有第一天上涨。
- 刚刚突破长期平台。
- 4H趋势刚转强。
- 1H仍不断创新高。
- 巨量突破后稳稳守住平台。

这套不是“涨幅榜直接空”，而是“上涨末期确认转弱后才空”。

==================================================
七、C4 恐慌反转多
==================================================

策略ID：

C4_PANIC_REVERSAL_LONG

中文：

C4 恐慌反转多

扫描：

跌幅前20。

目标图形：

连续下跌
→ 低位恐慌巨量
→ 跌不动或假跌破收回
→ 1H形成Higher Low
→ 15m确认做多

时间和空间：

1. 连续下跌至少3天。
2. ret_7d <= -25%。
3. range_position_30d <= 0.15。
4. 价格低于4H EMA20至少1.5 ATR。

恐慌衰竭：

1. 恐慌量比 >= 3.0。
2. 出现以下任一情况：
   - 长下影；
   - 跌破新低后快速收回；
   - 巨量但价格不再继续下跌；
   - 收盘重新站回原支撑；
   - close_location > 0.50。
3. 1H停止连续创新低。
4. 形成Higher Low。
5. 重新站上1H EMA20或突破局部高点。

15m入场：

1. 第一次回踩不破前低。
2. 形成Higher Low。
3. 重新站上EMA20。
4. 突破确认K高点。
5. 再启动量比 >= 1.2。

必须排除：

- 上涨趋势中的第一天下跌。
- 刚刚放量跌破长期平台。
- 1H仍连续创新低。
- 只有超跌，没有结构转强。
- 巨量下跌但收盘仍接近最低点。

这套不是“跌幅榜直接抄底”，而是“恐慌释放结束并确认转强后做多”。

==================================================
八、统一止损
==================================================

做多：

SL =
最近15m结构低点
-
0.2 × ATR14(15m)

做空：

SL =
最近15m结构高点
+
0.2 × ATR14(15m)

要求：

1. SL距离 > 6%，放弃。
2. 不能因为量能大而扩大SL。
3. SL变宽时只减少仓位。
4. 保存结构点和SL计算过程。
